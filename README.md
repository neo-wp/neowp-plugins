# neoWP Plugin Mirror

This GitHub repository is a mirror of the official WordPress.org plugin directory SVN repositories for neoWP plugins.

Official WordPress.org plugin pages:

- https://wordpress.org/plugins/neo-alt/
- https://wordpress.org/plugins/neo-animate/
- https://wordpress.org/plugins/neo-duplicate/
- https://wordpress.org/plugins/neo-optimize/
- https://wordpress.org/plugins/neo-rename/
- https://wordpress.org/plugins/neo-replace/

Feedback and improvement suggestions are welcome at https://neo-wp.com/feedback/.
