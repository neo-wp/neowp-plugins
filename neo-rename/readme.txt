### Maximize your image SEO with AI efficiently. Free or with your own API connection. ###
Rename your images and videos with AI in a flash and improve your website's SEO performance. The AI includes the image content and website context around the image when generating names. All references are automatically updated across the entire database.
Thanks to live preview, search and replace function, batch processing, and intelligent renaming rules you optimize your media library in no time and increase your website's visibility.

### Installation & Activation ###
= Installation via the WordPress Plugin Directory =
- Open the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New Plugin
- Search for „neo Rename“ and click on “Install Now”.
- After installation click on “Activate”.
= Installation of neo Rename from the official neoWP website =
- Download the Renamer plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-rename/?ref=wp-org).
- Open the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New Plugin > Upload Plugin > Activate Plugin
= Manual installation of neo Rename via FTP =
- Download the Renamer plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-rename/?ref=wp-org).
- Extract the ZIP file and upload the folder neo-rename via FTP to the `/wp-content/plugins/` directory of your WordPress installation.
- Go to the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > In the list click on „neo Rename“ and click on “Activate”.
= After activating the Renamer plugin =
- Click in the side bar in the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) on “neoWP” to review and adjust the default options.
- Adjust the “neo Rename” settings to your individual requirements.

### In short ###
**What is neoRename?**

The plugin [neoRename](https://neo-wp.com/plugin/neo-rename/) is a **WordPress plugin** that lets you efficiently **rename images, videos and other media files** in your media library. It automatically updates all references in the database to update existing links and improve your **SEO ranking**.

### SEO benefits? ###
**What benefits does neoRename offer for SEO?**

The plugin [neoRename](https://neo-wp.com/plugin/neo-rename/) **optimizes image titles, filenames and slugs**, creates **SEO-friendly redirects** (301 redirects) and can automatically generate missing **alt texts** from image titles. This sustainably improves your website’s visibility in search engines.

### Bulk renaming? ###
**Can I rename multiple files at once?**

Yes, with the built-in **bulk or batch processing** you can rename multiple files at once with [neoRename](https://neo-wp.com/plugin/neo-rename/). A **preview feature** shows you all planned changes in advance.

### Supported formats? ###
**Which file formats can I rename?**

**All common media formats** are supported by [neoRename](https://neo-wp.com/plugin/neo-rename/) for **images, videos and documents**, including: **JPG, PNG, WEBP, SVG, PDF, MP4, MOV, MP3, ZIP and many more**.

### Redirects & references? ###
**What happens to my existing image URLs after renaming?**

When renaming, [neoRename](https://neo-wp.com/plugin/neo-rename/) automatically updates **all references** in your WordPress database, including **post content**, **ACF fields** and even in **PHP arrays**. In addition, a **301 redirect** ensures that the old image links already indexed by Google remain reachable. This keeps your **SEO performance stable** and prevents losing rankings due to broken links.

### Before renaming ###
**What should I consider before renaming?**

Renaming files in WordPress can affect existing image references and links. **Before renaming media we recommend:**

**✅ Make a backup:** Create a [backup](https://wordpress.org/plugins/updraftplus/) of your site before renaming many files at once.

**✅ Start with single files:** Test renaming with [neoRename](https://neo-wp.com/plugin/neo-rename/) on individual files first.

**🛠️ Clear plugin cache:** If issues occur after renaming, clearing the plugin cache may help as old image references might still be stored there. See how to [clear cache](https://elementor.com/blog/how-to-clear-cache-for-one-website/).

**🛠️ Clear browser cache:** If wrong or old images still appear, clearing the [browser cache](https://developer.chrome.com/docs/devtools/storage/cache) can update stale references.

**🔙 Use the undo function:** With one click you can revert changes in [neoRename](https://neo-wp.com/plugin/neo-rename/#content) if something’s not right.

**🧠 SEO tip:** By redirecting old URLs with [neoRename](https://neo-wp.com/plugin/neo-rename/#content) you avoid negative impacts on your Google ranking!

**Yes**, the [neoRename](https://neo-wp.com/plugin/neo-rename/) plugin includes an **undo function** that restores previous filenames, titles and slugs after renaming.

### Download with Safari ###
**Why is only a folder shown when downloading?**

**If you use Safari** your Mac may automatically unzip the ZIP file. Instead of the ZIP file you then only get the unzipped folder. You can’t upload this directly to WordPress.

Solution: Open **Safari settings** and disable the option **”Open safe files after downloading”**. After that the ZIP file remains as you need it.

Exact details are shown in the video titled ”How to disable Safari auto extract for ZIP files when downloading WordPress plugins” on YouTube.
