### Installation & Activation ###
= Installation via the WordPress Plugin Directory =
- Open the [WordPress dashboard](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New
- Search for “neo Optimize” and click “Install Now”.
- After installation click “Activate”.
= Installation from neo Optimize from the official neoWP website =
- Download the Image Optimizer plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-optimize/?ref=wp-org).
- Open the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New > Upload Plugin > Activate Plugin
= Manual installation of neo Optimize via FTP =
- Download the Image Optimizer plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-optimize/?ref=wp-org).
- Extract the ZIP file and upload the neo-optimize folder via FTP to the `/wp-content/plugins/` directory of your WordPress installation.
- Go to the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > In the list click on “neo Optimize” and click on “Activate”.
= After activating the Image Optimizer plugin =
- Click in the side bar in the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) on „neoWP“ to review and adjust the default options.
- Adjust the „neo Optimize” settings to your individual requirements.

== Frequently Asked Questions ==
### Features of neo Optimize ###
**Which features are included in the plugin?**

The main features of the Image Optimizer plugin are:

- ✅ Maximize the SEO ranking of your images 🎉
- ✅ Original images and database remain untouched
- ✅ Resizing on your own server
- ✅ Free AVIF and WebP support for served images
- ✅ Optimization of neoDraw SVG graphics
- ✅ Image scaling based on the display size in the frontend

### In short ###
**What is neoOptimize?**

The [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) plugin is a **WordPress image optimization plugin**. It automatically reduces images to the actually required display size and converts image files to the efficient **AVIF format**. This makes images load faster and your website more performant, which positively affects **SEO ranking**.

What makes [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) special is that the **original images remain unchanged** and the optimized versions are stored in a separate cache directory. The plugin also works **without credit packages** because it optimizes images **for free on your own server**.

### Local optimization ###
**Are my images sent to external servers?**

The [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) plugin processes your images **directly on your own server**. Local server functions such as **Imagick** or **PHP GD** are used for image optimization. This means you **do not need credit packages** for external image services or any additional cloud processing.

This makes the optimization **free**, **privacy-friendly** and **independent** from external providers.

### Original images remain intact ###
**Does neoOptimize change my original images?**

Your original images and database remain **fully intact**. The [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) plugin only creates **optimized copies in the cache** and serves those in the frontend. The original files in your media library are not overwritten.

Your **WordPress database also remains untouched**. When the site loads, only the image URL in the frontend is replaced with the optimized cache version.

**If you deactivate or uninstall neoOptimize, everything returns to the way it was.**

### WebP and image quality ###
**What image quality should I set?**

For most websites we recommend an **AVIF quality of 75%**. The **AVIF format** is very efficient, so even lower quality settings often still look very good and produce significantly smaller files. You can also switch to the more widely supported WebP format for maximum compatibility.

In the [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) settings you can conveniently select the quality and directly evaluate it via a **preview with file size**. This helps you quickly find the right balance between high image quality and fast loading times.

### Retina factor ###
**What does the retina factor do?**

The **retina factor** controls the **pixel density** at which images are displayed for high-resolution screens. A **higher value** makes images appear **sharper** on retina displays but also increases file size.

The [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) plugin uses a **default** **retina factor of 1.5x** to improve the rendering of small text, icons and image details on retina displays. In the [Pro version](https://neo-wp.com/pricing/) you can set the retina factor individually and compare it directly in the preview.

### Clear cache ###
**When should I clear the neoOptimize cache?**

Under normal operation it is **not necessary** to clear the neoOptimize cache. The clear cache button can be useful if you want to **remove old image variants after many tests** or clean up after major changes to image sizes in a page builder. Afterwards the optimized images are **automatically regenerated** when they are needed again in the frontend.

If you change image quality, the retina factor or other **optimization settings**, [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) **automatically creates new optimized images**. When an image is **deleted** from the WordPress media library the associated cache files are **automatically removed**. Even optimized images that were renamed with [neoRename](https://neo-wp.com/plugin/neo-rename/) are cleaned up automatically.

The **Clear cache** button is therefore mainly intended as a **reset and cleanup function**.

### Page Builder ###
**Does neoOptimize work with my page builder?**

**Yes**, [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) works with all common page builders. These include [Bricks](https://bricksbuilder.io/), [Elementor](https://elementor.com/), [Divi](https://www.elegantthemes.com/gallery/divi/), [Beaver](https://www.wpbeaverbuilder.com/), [Oxygen](https://oxygenbuilder.com/), [Breakdance](https://breakdance.com/) and [Gutenberg](https://wordpress.org/gutenberg/).

neoOptimize can **automatically read the configured image sizes** and use them as the basis for optimization. This ensures the image is adapted as closely as possible to the actual display size and cached for fast delivery.

### Override image sizes ###
**Can I set image size and quality per image manually?**

**Yes.** You can override the automatically detected optimization per image using [**HTML attributes**](https://www.w3schools.com/html/html_attributes.asp). This is especially useful when an image is displayed differently in a page builder than it can be detected automatically. Examples:

`<img data-neo-optimize--width="320px" src="...">`  

`<img data-neo-optimize--height="180px" src="...">`  

`<img data-neo-optimize--quality="75" src="...">`

With the [Pro version](https://neo-wp.com/pricing/) you can additionally control the **retina factor** and the algorithm used per image:

`<img data-neo-optimize--retina="150" src="...">  

<img data-neo-optimize--algorithm="imagick" src="...">`

### Supported formats ###
**Which image formats does neoOptimize support?**

The image optimization in [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) supports many common raster formats, including [JPG](https://jpeg.org/), [JPEG](https://jpeg.org/), [PNG](https://www.adobe.com/creativecloud/file-types/image/raster/png-file.html), [GIF](https://www.adobe.com/creativecloud/file-types/image/raster/gif-file.html), [WebP](https://developers.google.com/speed/webp), [AVIF](https://caniuse.com/avif), [BMP](https://www.adobe.com/creativecloud/file-types/image/raster/bmp-file.html), [HEIC](https://en.wikipedia.org/wiki/High_Efficiency_Image_File_Format), [HEIF](https://en.wikipedia.org/wiki/High_Efficiency_Image_File_Format), [TIFF](https://www.adobe.com/creativecloud/file-types/image/raster/tiff-file.html) and many other formats if they can be processed on your server by [Imagick](https://imagemagick.org/) or [PHP GD](https://www.php.net/manual/en/book.image.php).

Raster images are optimized, scaled and stored as **[AVIF](https://developers.google.com/search/blog/2024/08/happy-avifriday)** files in the cache. In addition, neoOptimize can also optimize special [neoDraw](https://neo-wp.com/plugin/neo-draw/) [SVG graphics](https://de.wikipedia.org/wiki/Scalable_Vector_Graphics) for frontend output.

### neoDraw SVGs optimize ###
**How does neoOptimize optimize drawings from neoDraw?**

If an image was created with [neoDraw](https://neo-wp.com/plugin/neo-draw/), [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) can automatically optimize it when serving it in the frontend. Unnecessary **editor data is removed** for display and embedded raster images are converted to the efficient **AVIF format**.

The original neoDraw file remains fully intact and editable. Visitors get a slimmer, faster version in the frontend while you can still work with the editable original drawing in the backend.

### Download with Safari ###
**Why is only a folder shown when downloading?**

**If you use Safari**, your Mac may automatically extract the ZIP file. Instead of the ZIP file you then only get the extracted folder. You cannot upload this directly to WordPress.

Solution: Open **Safari preferences** and disable the option **”Open safe files after downloading”**. After that the ZIP file will remain as you need it.

The video titled ”How to disable Safari auto extract for ZIP files when downloading WordPress plugins” on YouTube shows you exact details.
