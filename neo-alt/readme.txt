== Description ==
### Create alt texts and image titles directly in WordPress with AI - 300 free image alt text generations included every month! ###
Create suitable alt texts and image titles directly in your WordPress media library. neoAlt recognizes the image content, takes into account the context of the page where it is used, and provides clear suggestions for better accessibility and image SEO.

With filters, search, and bulk processing you can also enhance large image collections quickly. You can review and edit every suggestion and save only when you want.

### 🚀️ Main Features of neo Alt ###
- ✅ Automatically create SEO-friendly alt texts for WordPress images using AI 🎉
- ✅ Find and fill missing alternative texts across the entire WordPress media library
- ✅ Edit image titles and alt text individually, together, or via bulk generation
- ✅ Analyze visible image content for precise and understandable image descriptions
- ✅ Consider page context and existing media titles for appropriate alt texts
- ✅ Improve accessibility and image SEO with meaningful image metadata
- ✅ Review AI suggestions before saving, adjust manually or discard
- ✅ Save individual changes or accept all reviewed suggestions at once

- ✅ Sort media by upload date, modified date, title, or URL

- ✅ Character counter for alt texts with a recommendation of 80 to 125 characters

### Installation & Activation ###
= Installation via the WordPress Plugin Directory =
- Open the [WordPress dashboard](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New
- Search for “neo Alt” and click “Install Now”.
- After installation click “Activate”.
= Installation from neo Alt from the official neoWP website =
- Download the Alt-Text Generator plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-alt/?ref=wp-org).
- Open the [WordPress dashboard](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New > Upload Plugin > Activate Plugin
= Manual installation of neo Alt via FTP =
- Download the Alt-Text Generator plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-alt/?ref=wp-org).
- Unzip the ZIP file and upload the neo-alt folder via FTP to the /wp-content/plugins/ directory of your WordPress installation.
- Go to the [WordPress dashboard](https://wordpress.org/documentation/article/administration-screens/) > Plugins > In the list click “neo Alt” and click “Activate”.
= After activating the Alt-Text Generator plugin =
- Click “neoWP” in the sidebar of the [WordPress dashboard](https://wordpress.org/documentation/article/administration-screens/) to review and adjust the default options.
- Adjust the “neo Alt” settings to your individual requirements.

### Download with Safari ###
**Why is only a folder shown when downloading?**

**If you use Safari**, your Mac might automatically unzip the ZIP file. Instead of the ZIP file you then only get the unzipped folder. You cannot upload this folder directly to WordPress.

Solution: Open **Safari Preferences** and disable the option **”Open safe files after downloading”**. After that the ZIP file will remain as you need it.

You can find exact details in the video titled ”How to disable Safari auto extract for ZIP files when downloading WordPress plugins” on YouTube.
