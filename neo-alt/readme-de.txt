### Erstelle Alt-Texte und Bildtitel direkt in WordPress per KI - 300 kostenlose Bild Alt Text Generierungen jeden Monat enthalten! ###
Erstelle passende Alt-Texte und Bildtitel direkt in deiner WordPress Mediathek. neoAlt erkennt den Bildinhalt, bezieht den Kontext der verwendeten Seite ein und liefert klare Vorschläge für bessere Barrierefreiheit und Bild-SEO.

Mit Filtern, Suche und Bulk-Verarbeitung ergänzt du auch große Bildbestände schnell. Jeden Vorschlag kannst du prüfen, bearbeiten und erst dann speichern.

### Installation & Aktivierung ###
= Installation über das WordPress Plugin Directory =
- Öffne das [WordPress-Backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Neues Plugin hinzufügen
- Suche nach „neo Alt“ und klicke auf „Jetzt installieren“.
- Nach der Installation klicke auf „Aktivieren“.
= Installation von neo Alt von der offiziellen neoWP-Website =
- Lade dir das Alt-Text Generator Plugin von der offiziellen Website [neo-wp.com](https://neo-wp.com/plugin/neo-alt/?ref=wp-org) herunter.
- Öffne das [WordPress-Backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Neues Plugin hinzufügen > Plugin hochladen > Plugin aktivieren
= Manuelle Installation von neo Alt per FTP =
- Lade dir das Alt-Text Generator Plugin von der offiziellen Website [neo-wp.com](https://neo-wp.com/plugin/neo-alt/?ref=wp-org) herunter.
- Entpacke die ZIP-Datei und lade den Ordner neo-alt per FTP in das Verzeichnis `/wp-content/plugins/` deiner WordPress-Installation.
- Gehe ins [WordPress-Backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > In der Liste auf „neo Alt“ und klicke auf „Aktivieren“.
= Nach der Aktivierung vom Alt-Text Generator Plugin =
- Klicke in der Side Bar im [WordPress-Backend](https://wordpress.org/documentation/article/administration-screens/) auf „neoWP“, um die Standardoptionen zu überprüfen und anzupassen.
- Passe die „neo Alt“-Einstellungen an deine individuellen Anforderungen an.

### Download mit Safari ###
**Warum wird beim Download nur ein Ordner angezeigt?**

**Wenn du Safari benutzt**, kann es sein, dass dein Mac die ZIP-Datei automatisch entpackt. Statt der ZIP-Datei bekommst du dann nur den entpackten Ordner. Diesen kannst du nicht direkt in WordPress hochladen.

Lösung: Öffne die **Safari-Einstellungen** und deaktiviere dort die Option **"Sichere Dateien nach dem Laden öffnen"**. Danach bleibt die ZIP-Datei so, wie du sie brauchst.

Genaue Details dazu zeigt dir das Video mit dem Titel "How to disable Safari auto extract for ZIP files when downloading WordPress plugins" auf YouTube.
