### Duplicate images for SEO for page specific ALT texts. ###
Duplicate images, videos and documents in the WordPress media library with just one click! The plugin allows, for example, using the same media in different posts with individual ALT tags and titles - ideal for SEO optimization and A/B tests.

### Installation & Activation ###
= Install via the WordPress Plugin Directory =
- Open the [WordPress dashboard](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New Plugin
- Search for „neo Duplicate“ and click “Install Now”.
- After installation click “Activate”.
= Installation from neo Duplicate  from the official neoWP website =
- Download the Duplicator plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-duplicate/?ref=wp-org).
- Open the [WordPress dashboard](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New Plugin > Upload Plugin > Activate Plugin
= Manual installation of neo Duplicate  via FTP =
- Download the Duplicator plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-duplicate/?ref=wp-org).
- Extract the ZIP file and upload the neo-duplicate folder via FTP to the `/wp-content/plugins/` directory of your WordPress installation.
- Go to the [WordPress dashboard](https://wordpress.org/documentation/article/administration-screens/) > Plugins > In the list click “neo Duplicate” and click “Activate”.
= After activating the Duplicator plugin =
- In the side bar of the [WordPress dashboard](https://wordpress.org/documentation/article/administration-screens/) click “neoWP” to review and adjust the default options.
- Adjust the “neo Duplicate” settings to your individual requirements.

### In short ###
**What is neoDuplicate?**

The plugin [neoDuplicate](https://neo-wp.com/plugin/neo-duplicate/) is a **WordPress plugin for duplicating images, videos, PDFs and other media files** directly in the Media Library. With one click you create your own copy of the file, including existing image sizes and media information.

This is especially helpful if you want to use the same image in multiple places but need different **alt texts, titles, captions or descriptions** per page. That way your Media Library stays flexible and you can prepare media cleanly for SEO, layouts and editorial variants.

### Why duplicate an image? ###
**Why should I duplicate an image in WordPress?**

Duplicating an image makes sense when the same file is used in different posts, pages or products with their own **alt text, captions, titles or descriptions**. For SEO it can be better to describe an image differently depending on the context instead of using the same media entry everywhere.

Copying also helps with image editing in WordPress: you can crop, rotate or test an image for a specific post without changing the original media entry for other uses. Duplicating is also handy as a quick backup before changes or to reuse media in variants.

### Preserve metadata ###
**Are all metadata preserved when duplicating?**

**Yes.** [neoDuplicate](https://neo-wp.com/plugin/neo-duplicate/) creates a copy of the media file and preserves important media information such as **title, alt text, caption and description**. Existing image sizes are also duplicated so the copy can be used immediately as an independent media entry.

After duplicating you can change the copy’s metadata independently from the original. This lets you use the same image multiple times without changes to alt text or caption automatically affecting other usages.

### Keep upload date ###
**Can I keep the upload date when duplicating?**

**Yes.** When duplicating the original upload date can be preserved so the copied file remains associated with the original time and is easier to find in the Media Library. This is useful if you sort your media by date or want to keep older projects organized.

Alternatively, a copy can be treated as a new media entry if you want it to appear as a current variant. You decide based on your workflow whether the copy stays with the original or appears higher in the Media Library.

### Download with Safari ###
**Why do I only see a folder when downloading?**

**If you use Safari,** your Mac may automatically unzip the ZIP file. Instead of the ZIP file you then only get the unzipped folder. You cannot upload this directly to WordPress.

Solution: Open **Safari Preferences** and disable the option **”Open safe files after downloading”**. After that the ZIP file will remain as you need it.

The video titled ”How to disable Safari auto extract for ZIP files when downloading WordPress plugins” on YouTube shows the exact details.
