== Description ==
### Bilder duplizieren für SEO für seitenspezifische ALT-Texte. ###
Dupliziere Bilder, Videos und Dokumente in der WordPress-Mediathek mit nur einem Klick! Das Plugin ermöglicht beispielsweise die Verwendung gleicher Medien in verschiedenen Posts mit individuellen ALT-Tags und Titeln - ideal für SEO-Optimierung und A/B-Tests.

### Installation & Aktivierung ###
= Installation über das WordPress Plugin Directory =
- Öffne das [WordPress-Backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Neues Plugin hinzufügen
- Suche nach „neo Duplicate“ und klicke auf „Jetzt installieren“.
- Nach der Installation klicke auf „Aktivieren“.
= Installation von neo Duplicate von der offiziellen neoWP-Website =
- Lade dir das Duplicator Plugin von der offiziellen Website [neo-wp.com](https://neo-wp.com/plugin/neo-duplicate/?ref=wp-org) herunter.
- Öffne das [WordPress-Backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Neues Plugin hinzufügen > Plugin hochladen > Plugin aktivieren
= Manuelle Installation von neo Duplicate per FTP =
- Lade dir das Duplicator Plugin von der offiziellen Website [neo-wp.com](https://neo-wp.com/plugin/neo-duplicate/?ref=wp-org) herunter.
- Entpacke die ZIP-Datei und lade den Ordner neo-duplicate per FTP in das Verzeichnis `/wp-content/plugins/` deiner WordPress-Installation.
- Gehe ins [WordPress-Backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > In der Liste auf „neo Duplicate“ und klicke auf „Aktivieren“.
= Nach der Aktivierung vom Duplicator Plugin =
- Klicke in der Side Bar im [WordPress-Backend](https://wordpress.org/documentation/article/administration-screens/) auf „neoWP“, um die Standardoptionen zu überprüfen und anzupassen.
- Passe die „neo Duplicate“-Einstellungen an deine individuellen Anforderungen an.

### Kurz und knapp ###
**Was ist neoDuplicate?**

Das Plugin [neoDuplicate](https://neo-wp.com/plugin/neo-duplicate/) ist ein **WordPress-Plugin zum Duplizieren von Bildern, Videos, PDFs und anderen Mediendateien** direkt in der Mediathek. Mit einem Klick erstellst du eine eigene Kopie der Datei, inklusive der vorhandenen Bildgrößen und Medieninformationen.

Das ist besonders hilfreich, wenn du dasselbe Bild an mehreren Stellen verwenden möchtest, aber pro Seite unterschiedliche **Alt-Texte, Titel, Beschriftungen oder Beschreibungen** brauchst. So bleibt deine Mediathek flexibel und du kannst Medien sauber für SEO, Layouts und redaktionelle Varianten vorbereiten.


### Warum ein Bild duplizieren? ###
**Warum sollte ich ein Bild in WordPress duplizieren?**

Ein Bild zu duplizieren ist sinnvoll, wenn dieselbe Datei in unterschiedlichen Beiträgen, Seiten oder Produkten mit eigenen **Alt-Texten, Captions, Titeln oder Beschreibungen** genutzt werden soll. Gerade für SEO kann es besser sein, ein Motiv je nach Kontext anders zu beschreiben, statt überall denselben Medieneintrag zu verwenden.

Auch bei der Bildbearbeitung in WordPress hilft eine Kopie: Du kannst ein Bild für einen bestimmten Beitrag anders zuschneiden, drehen oder testen, ohne den ursprünglichen Medieneintrag für andere Stellen zu verändern. Ebenso praktisch ist das Duplizieren als schnelles Backup vor Änderungen oder zum Wiederverwenden von Medien in Varianten.


### Metadaten übernehmen ###
**Werden alle Metadaten beim Duplizieren übernommen?**

**Ja.** [neoDuplicate](https://neo-wp.com/plugin/neo-duplicate/) erstellt eine Kopie der Mediendatei und übernimmt dabei wichtige Medieninformationen wie **Titel, Alt-Text, Beschriftung und Beschreibung**. Auch die vorhandenen Bildgrößen werden mit dupliziert, damit die Kopie direkt wie ein eigenständiger Medieneintrag verwendet werden kann.

Nach dem Duplizieren kannst du die Metadaten der Kopie unabhängig vom Original anpassen. So nutzt du dasselbe Motiv mehrfach, ohne dass Änderungen am Alt-Text oder an der Caption automatisch alle anderen Verwendungen beeinflussen.


### Upload-Datum beibehalten ###
**Kann ich das Upload-Datum beim Duplizieren beibehalten?**

**Ja.** Beim Duplizieren kann das ursprüngliche Upload-Datum beibehalten werden, damit die kopierte Datei zeitlich beim Original bleibt und in der Mediathek leichter wiederzufinden ist. Das ist besonders angenehm, wenn du deine Medien nach Datum sortierst oder ältere Projekte sauber zusammenhalten möchtest.

Alternativ kann eine Kopie auch als neuer Medieneintrag behandelt werden, wenn sie bewusst als aktuelle Variante erscheinen soll. So entscheidest du je nach Workflow, ob die Kopie organisatorisch beim Original bleibt oder in der Mediathek weiter oben einsortiert wird.

### Download mit Safari ###
**Warum wird beim Download nur ein Ordner angezeigt?**

**Wenn du Safari benutzt**, kann es sein, dass dein Mac die ZIP-Datei automatisch entpackt. Statt der ZIP-Datei bekommst du dann nur den entpackten Ordner. Diesen kannst du nicht direkt in WordPress hochladen.

Lösung: Öffne die **Safari-Einstellungen** und deaktiviere dort die Option **"Sichere Dateien nach dem Laden öffnen"**. Danach bleibt die ZIP-Datei so, wie du sie brauchst.

Genaue Details dazu zeigt dir das Video mit dem Titel "How to disable Safari auto extract for ZIP files when downloading WordPress plugins" auf YouTube.
