### Installation & Activation ###
= Installation via the WordPress Plugin Directory =
- Open the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New
- Search for "neo Animate" and click "Install Now."
- After installation click "Activate."
= Installation from neo Animate from the official neoWP website =
- Download the SVG Animation Plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-animate/?ref=wp-org).
- Open the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New > Upload Plugin > Activate Plugin
= Manual installation of neo Animate via FTP =
- Download the SVG Animation Plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-animate/?ref=wp-org).
- Unzip the ZIP file and upload the neo-animate folder via FTP to the `/wp-content/plugins/` directory of your WordPress installation.
- Go to the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > In the list click "neo Animate" and click "Activate."
= After activating the SVG Animation Plugin =
- Click in the side bar in the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) on "neoWP" to review and adjust the default options.
- Adjust the "neo Animate" settings to your individual requirements.

== Frequently Asked Questions ==
### Features of neo Animate ###
**Which features are included in the plugin?**

The key features of the SVG Animation Plugin are:

- ✅ Simple path animation for SVG drawings
- ✅ Triggers for scroll and hover animations
- ✅ Live preview of stroke-line effects
- ✅ Simple and powerful animation frame editor

### neoDraw - Transfer drawings ###
**How can I transfer drawings created with neoDraw to another website?**

Drawings created with [neoDraw](https://neo-wp.com/plugin/neo-draw/) can be downloaded like regular images as **SVG or PNG files** and uploaded to another WordPress instance. For SVG upload to work, it must either be enabled manually or use the [neoLibrary](https://neo-wp.com/plugin/neo-library/) for the upload. The drawings can **still be edited with neoDraw after the upload** because the drawing data is embedded in both the SVG and PNG formats.

### neoDraw - Export drawing ###
**Can I export neoDraw drawings as PNG files?**

**Yes**, drawings created with [neoDraw](https://neo-wp.com/plugin/neo-draw/) can be downloaded as **PNG files** via the [neoLibrary](https://neo-wp.com/plugin/neo-library/). All drawing data is embedded as metadata directly into the PNG file. Despite the pixel-based format, this allows **full restoration of the original SVG** including all editable drawing elements. If such a PNG file is later uploaded again with neoLibrary, it will automatically be converted back into an SVG file editable with neoDraw.

### neoDraw - File format ###
**In what format are neoDraw drawings saved?**

Drawings created with [neoDraw](https://neo-wp.com/plugin/neo-draw/) are stored in the WordPress media library as [vector graphics](https://en.wikipedia.org/wiki/Vector_graphics) in [SVG format](https://en.wikipedia.org/wiki/SVG) - just like regular images. In the file system these SVG files sit alongside the other images from the WordPress media library. Thus all drawings created with neoDraw can still be used after uninstalling.

All editor drawing data, including embedded images and animations from [neoAnimate](https://neo-wp.com/plugin/neo-animate/) & [neoMotion](https://neo-wp.com/plugin/neo-motion/), are stored directly in the SVG file. This keeps the drawing fully editable even after downloading and re-uploading - for example to another WordPress instance. In the frontend the SVG files are treated like ordinary images.

For maximum performance the [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) plugin removes the editor data automatically when serving the SVG files and converts embedded raster images to the efficient [WebP format](https://en.wikipedia.org/wiki/WebP).

### neoDraw - Drawings without Pro ###
**What happens to my drawings and animations without Pro?**

If you no longer use a Pro license, your existing **drawings and animations remain fully intact** and continue to work in the frontend.

The Pro features within the drawings (for example advanced animation settings) can no longer be edited without a license. Displaying and exporting is still possible because your drawings are stored as regular SVG files.

If you later switch back to neoPro, all Pro features become available again without restrictions.

### Download with Safari ###
**Why is only a folder shown when downloading?**

**If you use Safari**, your Mac may automatically unzip the ZIP file. Instead of the ZIP file you then only get the unzipped folder. You cannot upload this directly to WordPress.

Solution: Open **Safari Preferences** and disable the option **”Open safe files after downloading”**. The ZIP file will then remain as you need it.

The video titled ”How to disable Safari auto extract for ZIP files when downloading WordPress plugins” on YouTube shows exact details.
