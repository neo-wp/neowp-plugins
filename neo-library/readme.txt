### Bring order to your media library and see where your images are used! ###
Sort, duplicate, replace, and rename your images with ease. Upload media via drag and drop in parallel and optimize image size and metadata for better SEO results. 
With neoLibrary you have perfect control of your WordPress media library.

### Installation & Activation ###
= Install via the WordPress Plugin Directory =
- Open the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New
- Search for “neo Library“ and click “Install Now”.
- After installation click “Activate”.
= Install from neo Library from the official neoWP website =
- Download the Image Media Library plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-library/?ref=wp-org).
- Open the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New > Upload Plugin > Activate Plugin
= Manual installation of neo Library via FTP =
- Download the Image Media Library plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-library/?ref=wp-org).
- Unzip the ZIP file and upload the neo-library folder via FTP to the `/wp-content/plugins/` directory of your WordPress installation.
- Go to the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > In the list click on "neo Library" and click "Activate".
= After activating the Image Media Library plugin =
- Click in the sidebar in the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) on "neoWP" to review and adjust the default options.
- Adjust the "neo Library” settings to your individual requirements.

### Download with Safari ###
**Why is only a folder shown when downloading?**

**If you use Safari**, it may be that your Mac automatically unzips the ZIP file. Instead of the ZIP file you then only get the unzipped folder. You cannot upload this directly to WordPress.

Solution: Open **Safari preferences** and disable the option **”Open safe files after downloading”**. After that the ZIP file will remain as you need it.

The video titled ”How to disable Safari auto extract for ZIP files when downloading WordPress plugins” on YouTube shows exact details.
