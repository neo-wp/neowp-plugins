### Installation & Activation ###
= Installation via the WordPress Plugin Directory =
- Open the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New Plugin
- Search for “neo Draw” and click “Install Now”.
- After installation click “Activate”.
= Installation from neo Draw from the official neoWP website =
- Download the Whiteboard plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-draw/?ref=wp-org).
- Open the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > Add New > Upload Plugin > Activate the plugin
= Manual installation of neo Draw via FTP =
- Download the Whiteboard plugin from the official website [neo-wp.com](https://neo-wp.com/plugin/neo-draw/?ref=wp-org).
- Extract the ZIP file and upload the neo-draw folder via FTP to the `/wp-content/plugins/` directory of your WordPress installation.
- Go to the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) > Plugins > In the list click on "neo Draw" and click "Activate".
= After activating the Whiteboard plugin =
- Click in the sidebar of the [WordPress backend](https://wordpress.org/documentation/article/administration-screens/) on "neoWP" to review and adjust the default options.
- Adjust the "neo Draw” settings to your individual requirements.

### neoDraw optimize SVGs ###
**How does neoOptimize optimize drawings from neoDraw?**

When a graphic was created with [neoDraw](https://neo-wp.com/plugin/neo-draw/), [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) can automatically optimize it when serving it on the frontend. Unnecessary **editor data is removed** for display and embedded raster images are converted to the efficient **AVIF format**.

The original neoDraw file remains fully intact and editable. Visitors receive a leaner, faster version on the frontend while you can still work with the editable original drawing in the backend.

### neoDraw - transfer drawings ###
**How can I transfer drawings created with neoDraw to another website?**

Drawings created with [neoDraw](https://neo-wp.com/plugin/neo-draw/) can be downloaded like regular images as **SVG or PNG files** and uploaded to another WordPress instance. For SVG upload to work, it must either be enabled manually or the [neoLibrary](https://neo-wp.com/plugin/neo-library/) must be used for the upload. The drawings can **still be edited with neoDraw after the upload** because the drawing data is embedded in both the SVG and PNG formats.

### neoDraw - export drawing ###
**Can I export neoDraw drawings as a PNG file?**

**Yes**, drawings created with [neoDraw](https://neo-wp.com/plugin/neo-draw/) can be downloaded as **PNG files** via the [neoLibrary](https://neo-wp.com/plugin/neo-library/). All drawing data is embedded as metadata directly into the PNG file. Even with the raster format, the **full restoration of the original SVG is possible** - including all editable drawing elements. If such a PNG file is later reuploaded with neoLibrary, it is automatically converted back into an SVG file that can be edited with neoDraw.

### neoDraw - file format ###
**In which format are neoDraw drawings stored?**

Drawings created with [neoDraw](https://neo-wp.com/plugin/neo-draw/) are stored in the WordPress media library as [vector graphics](https://en.wikipedia.org/wiki/Vector_graphics) in [SVG format](https://en.wikipedia.org/wiki/SVG) - just like regular images. On the file system these SVG files sit alongside the other images in the WordPress media library. Therefore all drawings created with neoDraw can still be used even after uninstalling the plugin.

All editor drawing data, including embedded images and animations from [neoAnimate](https://neo-wp.com/plugin/neo-animate/) & [neoMotion](https://neo-wp.com/plugin/neo-motion/), is stored directly in the SVG file. This ensures the drawing remains fully editable even after downloading and reuploading - for example on another WordPress instance. On the frontend the SVG files are treated like ordinary images.

For maximum performance the [neoOptimize](https://neo-wp.com/plugin/neo-optimize/) plugin automatically removes the editor data when serving the SVG files and converts embedded raster images to the efficient [WebP format](https://en.wikipedia.org/wiki/WebP).

### neoDraw - drawings without Pro ###
**What happens to my drawings and animations without Pro?**

If you no longer use a Pro license, your existing **drawings and animations remain fully intact** and continue to work on the frontend.

The Pro features inside the drawings (e.g. advanced animation settings) cannot be edited without a license. Displaying and exporting is still possible because your drawings are stored as regular SVG files.

If you switch back to neoPro later, all Pro features become available again without restrictions.

### neoDraw - and the neoUniverse ###
**How does neoDraw work with the other plugins?**

The **neoDraw** plugin unfolds its full power in combination with the other plugins of the neoUniverse - especially in practical use cases. For example: You run a web design agency and want to integrate a visual route description on a client’s website. With **neoDraw** you create a sketch showing the route to the location directly on a map excerpt. Then you use **neoAnimate** to display the route as an animated path so visitors immediately see how to get there. To ensure the graphic is optimally indexed by search engines you name it SEO-friendly with **neoRename** and add the location to the filename. The **neoOptimize** plugin automatically handles compression and adapts the image size to different devices. At the same time **neoLazy** ensures the image only loads when it is actually needed - saving load time and improving the user experience. If the client’s location changes you can quickly and losslessly replace the graphic with **neoReplace** - all links remain intact. With **neoLibrary** you always keep an overview of your media files and see exactly which images are used in which posts - ideal for cleaning up and organizing.

### Download with Safari ###
**Why does only a folder appear when downloading?**

**If you use Safari**, your Mac may automatically unzip the ZIP file. Instead of the ZIP file you then only get the unzipped folder. You cannot upload this directly to WordPress.

Solution: Open **Safari preferences** and disable the option **”Open safe files after downloading”**. After that the ZIP file will remain as you need it.

The video titled ”How to disable Safari auto extract for ZIP files when downloading WordPress plugins” on YouTube shows exact details.
